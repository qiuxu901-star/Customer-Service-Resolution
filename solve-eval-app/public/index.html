评估助手

用大白话向助手提问，即可获取平台数据与分析结论；也可以直接把一段会话贴进来让它检测。助手默认走规则路由（零依赖）；在设置页接入大模型后，可理解更自由的说法（失败自动降级）。

检测台

输入司机与客服的真实会话及系统结果，引擎按《检测规则清单》独立还原诉求、分环节验证、输出可解释判定；信息不足时会先向你提问。

格式：司机 / 客服 / AI 开头，支持空行分隔轮次。语音转写文本同样按此格式粘贴（R6）
缺失即标记、不补造（R2/R4）；阻断级缺失引擎会先提问
字段：session_text（必填）/ intent_id / intent_name / scene_id / scene_name / ai_reply（必填）/ exec_result / source_type / session_time。导入后逐条实时检测，出一条看一条。

人工复核台

检测结果自动落入「待复核」。六态看板逐条确认：确认通过 / 驳回修正 / 补充证据 / 标记无法判断 / 提交标准事项。原检测结论永远保留，人工结论独立留痕。

从左侧选择一条复核任务

数据看板

五层指标：解决能力总览 → 决策链路质量 → 人工替代潜力 → 问题归因 → 纠正进展。全部指标注明分子分母；无法判断与能力指标并列披露。点击指标卡可下钻到全盘记录。

全盘记录

每一次输入、每一次检测、每一条复核都在此留痕，可追溯、可导出。

材料中心

版本管理（每次导入 / 增删改都记版本，可回滚）

标准库

标准是「尺子」：意图定义、场景定义、意图-场景映射、场景检查清单、回复规则、正负案例。尺子缺失时引擎按 UR 规则拒判，不换一把似是而非的尺子。

新增标准

标准事项（由复核台「提交标准事项」产生）

纠正任务

从复核台派生的待纠正事项：问题对象、当前等级、期望等级、归因、改进建议、复验结果。必须区分「原 AI 能力修正」与「评价标准修正」——改判据不等于 AI 变强。

设置

操作人姓名用于复核留痕；接入大模型后引擎与评估助手切换为 LLM 模式（失败自动降级规则引擎并标注）。

大模型配置（可选，OpenAI 兼容接口）
不配置大模型时，引擎与助手以规则模式运行：结论为启发式预判，必须经人工复核确认（G9 纪律）。

助手配置

维护评估助手自身：系统提示词、路由规则（可启停）、能力清单、技能知识库、展示文案。修改即时生效——大模型通道用提示词与知识库，规则通道用路由开关与展示文案。
